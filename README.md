# PhonoPitch Lab

Real-time pitch tracking and phonetics teaching tool developed by Alfonso C. Rodríguez Fernández-Peña, Department of English, French and German Philology, University of Oviedo (Spain).

## Overview

PhonoPitch Lab is an open-access web application designed for phonetics teaching, speech analysis and research. The software provides real-time visualization of fundamental frequency (F0) contours directly in the browser without requiring installation.

## Features

* Real-time F0 visualization
* Pitch tracking
* Browser-based operation
* Phonetics teaching support
* Open-access web deployment
* Cross-platform compatibility
